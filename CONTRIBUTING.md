# Contributing

1. **Sign once.** On your first pull request the CLA bot asks you to post a one-line signing statement. That covers all of your later contributions ([CLA.md](CLA.md)). If you contribute for an organization, it signs the Corporate CLA first ([CCLA.md](CCLA.md)), and its contributors are allowlisted.
2. **Pick a cell or a track.** Unread cells are open work. Comment on an issue to claim it.
3. **Add readings** under `seam/readings/<your-handle>/<lens>.yaml`, copied from the [template](seam/readings/TEMPLATE.yaml). One file per lens.
4. **Open a pull request.** CI runs the validator and the data-handling guard.

## Rules

- **Cite public sources.** Every reading has at least one linkable source and an evidence grade. Mark judgement as `inferred` or `speculative`.
- **No dollar figures on cells.** The validator rejects them.
- **Postures are arguments, not verdicts.** Disagree by adding your own reading with a different lens. Don't edit someone else's.
- **Never contribute** personal information, confidential or export-controlled information, or third-party material you cannot license.
- **Changes to the rubric itself** (layers, capabilities, vocabulary) start as a rubric-proposal issue.
- Every new Markdown file carries a `Handling:` line.

Be kind and specific. See [CODE_OF_CONDUCT.md](CODE_OF_CONDUCT.md).
